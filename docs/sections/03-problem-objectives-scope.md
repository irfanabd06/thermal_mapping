### 3.1. Problem Statement

> **How might we make cooling in tropical greenhouses more effective when heat builds up unevenly across the greenhouse?**

Without spatially resolved thermal data or a validated thermal model, cooling layouts cannot be evaluated before installation, and cooling cannot be directed to where and when crops need it.

### 3.2. Value to Farmers

Commercial farmers value a profitable greenhouse. A viable solution balances thermal performance, operating cost and crop value (Figure 8). Air-conditioning performs best but costs too much to run, while GH1's fans run continuously yet still leave hotspots (Figure 9). This project aims for better crop-zone thermal performance at equal or lower fan energy (R9, R10).

### 3.3. Objectives

1. **O1 Thermal characterisation:** identify where and when crop-zone hotspots occur in GH1, with measurements reliable enough to compare locations.
2. **O2 Cooling layout evaluation:** determine how the number, placement, direction and speed of fans affect crop-zone temperatures, before changes are installed.
3. **O3 Targeted cooling:** reduce crop-zone heat exposure compared with current operation by directing cooling where and when it is needed.

### 3.4. Scope of Work

Table 5 separates what this project commits to deliver in CDE4301 from the long-term application and from stretch goals. The greenhouse structure is fixed; only fans are varied. Physical tests use four floor fans in the germination section, a shared test section in which the CFD model and the digital twin are tested together.

[[table: table-scope | Table 5: Scope of work]]

**Out of scope:** changes to GH1's structure, vents, misting or shading; guaranteeing crop-optimal temperatures at peak sun; air-conditioning; proving yield or profit improvement; and developing weather forecasts (NEA data is used as an input).
